EXEMPLO 3: TESTE DE NORMALIDADE
================================================================================

Arquivo: resumo_testes_20260525_143000.csv
Campo: Normalidade_p

RESULTADO: 0.1234 (para MT)

INTERPRETACAO:
  "Teste Shapiro-Wilk
   H₀: Os resíduos seguem distribuição normal
   
   p = 0.1234 > 0.05
   
   CONCLUSÃO: Não rejeitamos H₀
   'Podemos assumir que os resíduos são aproximadamente normais'"

RESULTADO: 0.0012 (para LP) — PROBLEMA!

INTERPRETACAO:
  "p = 0.0012 < 0.05
   
   CONCLUSÃO: Rejeitamos H₀
   'Os resíduos NÃO seguem distribuição normal'
   
   IMPACTO:
   • Testes de significância podem estar inválidos
   • Mas estimativas de coeficientes ainda são válidas
   • Intervalos de confiança podem estar ligeiramente errados
   
   SOLUÇÃO:
   • Usar bootstrap para CIs robustos
   • Transformar Y (log, raiz, Box-Cox)
   • Com n=1050, normalidade não é tão crítica"

EXEMPLO 4: TESTE DE HOMOCEDASTICIDADE
================================================================================

Campo: Homocedasticidade_p

RESULTADO: 0.3421 (para MT) — BOM!

INTERPRETACAO:
  "Teste Breusch-Pagan
   H₀: Variância dos resíduos é constante
   
   p = 0.3421 > 0.05
   
   CONCLUSÃO: Não rejeitamos H₀
   'A variância é homogênea em todo o range de valores preditos'"

RESULTADO: 0.0045 (para LP) — PROBLEMA!

INTERPRETACAO:
  "p = 0.0045 < 0.05
   
   CONCLUSÃO: Rejeitamos H₀
   'Há heterocedasticidade (variância não-constante)'
   
   IMPACTO:
   • Erros padrão dos coeficientes estão ERRADOS
   • Intervalos de confiança estão ERRADOS
   • P-valores estão ERRADOS
   
   SOLUÇÃO:
   • Usar erros padrão robustos (Huber-White)
   • Transformar Y
   • Weighted least squares
   
   CÓDIGO R:
   library(sandwich)
   library(lmtest)
   coeftest(modelo_lp, vcov = vcovHC(modelo_lp, type = "HC1"))"

EXEMPLO 5: TESTE DE MULTICOLINEARIDADE (VIF)
================================================================================

Arquivo: vif_MT_20260525_143000.csv

Conteúdo:
┌────────────────────┬─────────┬──────────────┐
│ Variavel           │ VIF     │ Severidade   │
├────────────────────┼─────────┼──────────────┤
│ INSE_MEDIO_norm    │ 1.23    │ Aceitável    │
│ TIPO_ESCOLA_Priv   │ 2.14    │ Aceitável    │
│ AREA_Rural         │ 1.87    │ Aceitável    │
│ LOCALIZACAO_Inter  │ 3.45    │ Aceitável    │
└────────────────────┴─────────┴──────────────┘

INTERPRETACAO:
  "VIF (Variance Inflation Factor)
   
   INSE_MEDIO_norm: VIF = 1.23
   'Variância do coef é 1.23x maior que seria sem multicolinearidade
    Nenhuma correlação com outras variáveis'
   
   TIPO_ESCOLA_Privada: VIF = 2.14
   'Correlação leve com outras variáveis, mas aceitável'
   
   Todas < 5 → Sem problemas de multicolinearidade
   
   ESCALA DE REFERÊNCIA:
   • VIF = 1      → Sem correlação (ideal)
   • 1 < VIF < 5  → Aceitável
   • 5 < VIF < 10 → Moderada (investigar)
   • VIF > 10     → Severa (remover variáveis)"

EXEMPLO COM PROBLEMA:
Conteúdo hipotético:
┌────────────────────┬─────────┬──────────────┐
│ AREA_Rural         │ 8.23    │ Moderada     │
│ TIPO_ESCOLA_Priv   │ 11.45   │ SEVERA       │
└────────────────────┴─────────┴──────────────┘

INTERPRETACAO:
  "TIPO_ESCOLA_Privada tem VIF = 11.45 → PROBLEMA!
   
   Significa:
   'Privado está altamente correlacionado com outra(s) variável(is)'
   
   Provável causa:
   'Escolas privadas tendem a estar em áreas urbanas
    Escolas privadas tendem a ter maior INSE'
   
   SOLUÇÃO:
   • Remover uma das variáveis correlacionadas
   • Combinar em índice único
   • Usar PCA (Principal Component Analysis)
   • Usar regularização (Ridge/Lasso)"

EXEMPLO 6: TESTE DE INDEPENDENCIA (DURBIN-WATSON)
================================================================================

Campo: DW

RESULTADO: 1.98 — BOM!

INTERPRETACAO:
  "Durbin-Watson test
   
   DW = 1.98 ≈ 2
   
   Interpretação:
   'Os resíduos são independentes (sem autocorrelação)'
   
   Escala:
   • DW = 0   → Autocorrelação positiva EXTREMA
   • DW = 2   → Independência PERFEITA
   • DW = 4   → Autocorrelação negativa EXTREMA
   
   Intervalo aceitável: 1.5 < DW < 2.5
   p-valor > 0.05 → Não há autocorrelação significativa"

RESULTADO: 0.87 — PROBLEMA!

INTERPRETACAO:
  "DW = 0.87 < 1.5
   
   CONCLUSÃO: Há autocorrelação POSITIVA dos resíduos
   
   Significa:
   'Um resíduo grande é seguido por outro grande
    Não estão distribuídos aleatoriamente'
   
   Causa comum:
   'Dados ordenados por tempo ou espaço
    Observações próximas são mais similares'
   
   IMPACTO:
   • Erros padrão subestimados
   • P-valores muito pequenos (falsos positivos)
   • Previsões de intervalos são otimistas demais
   
   SOLUÇÃO:
   • Incluir lags (MEDIA_MT_anterior)
   • Usar modelos com estrutura temporal
   • ARIMA ou AR models
   • Agrupar dados por unidade"

EXEMPLO 7: OUTLIERS (COOK'S DISTANCE)
================================================================================

Arquivo: outliers_cooks_MT_*.png (gráfico visual)

O que é Cook's Distance:
  'Medida de quanto a regressão muda se você remover uma observação
   
   Cozinha do Chef:
   • Sal normal = resíduo pequeno
   • Sal demais = outlier com valor extremo
   
   Mas:
   • Uma pitada extra de sal em um prato simples = grande mudança (influente!)
   • Uma pitada extra em um stew com 10 ingredientes = muda pouco (não-influente)
   
   Cook's Distance combina os dois: valor extremo + influência'

Limiar: 4 / n_observacoes = 4 / 1050 = 0.0038

INTERPRETACAO:
  "Se Cook's D > 0.0038 → Observação é influente
   Se Cook's D < 0.0038 → Observação é normal
   
   Encontramos 34 observações influentes
   Representam 3.2% dos dados (aceitável)
   
   O QUE FAZER:
   • Verificar se são erros de digitação
   • Verificar se são casos especiais válidos
   • Refazer regressão sem elas e comparar coeficientes
   • Se coeficientes mudam muito → são influentes de verdade
   • Se mudam pouco → modelo é robusto"

EXEMPLO COM PROBLEMA:
  "Encontramos 150 observações influentes
   Representam 14.3% dos dados (PROBLEMA!)
   
   Significa:
   'Modelo depende muito de poucos dados extremos
    Não generaliza bem
    Resultados podem estar enviesados'
   
   AÇÃO IMEDIATA:
   • Investigar estas 150 escolas
   • Revisar coleta de dados
   • Considerar transformação ou subgrupos"

RESUMO VISUAL — COMO USAR ESTES EXEMPLOS
================================================================================

Quando você executar os scripts, receberá arquivos similares a estes.

Use este documento assim:

1. ABRIR: seu arquivo gerado (ex: resumo_modelos_*.csv)
2. PROCURAR: o valor que você quer entender
3. ENCONTRAR: a seção com exemplo parecido acima
4. LER: a interpretação
5. ADAPTAR: aos seus dados específicos

CHECKLIST RÁPIDO:

□ R² > 0.5? 
  → Se sim: ótimo, modelo explica bem
  → Se não: modelo fraco, revisar

□ Todos p < 0.05?
  → Se sim: todas variáveis significativas
  → Se não: considerar remover não-significativas

□ Normalidade p > 0.05?
  → Se sim: resíduos são normais
  → Se não: resultado menos confiável

□ Homocedasticidade p > 0.05?
  → Se sim: variância é constante
  → Se não: usar erros robustos

□ VIF < 5?
  → Se sim: sem multicolinearidade
  → Se não: remover variáveis correlacionadas

□ DW entre 1.5-2.5?
  → Se sim: independência OK
  → Se não: há autocorrelação

✓ Se passar em todos → MODELO EXCELENTE!
