COMO INTERPRETAR OS RESULTADOS

1. ABRIR: outputs_tabelas/coeficientes_MT_*.csv

   EXEMPLO:
   ┌──────────────────────┬──────────────┬─────────────┐
   │ Termo                │ Coeficiente  │ Sig         │
   ├──────────────────────┼──────────────┼─────────────┤
   │ (Intercept)          │ 275.34       │ ***         │
   │ INSE_MEDIO_norm      │  18.45       │ ***         │
   │ TIPO_ESCOLA_Privada  │  28.67       │ ***         │
   │ AREA_Rural           │ -12.34       │ ***         │
   │ LOCALIZACAO_Interior │  -5.67       │ **          │
   └──────────────────────┴──────────────┴─────────────┘

   INTERPRETAÇÃO:
   • *** = p < 0.001 (MUITO significativo)
   • **  = p < 0.01  (significativo)
   • *   = p < 0.05  (marginalmente significativo)
   • Sem marca = p ≥ 0.05 (não significativo)

   SIGNIFICADO DO COEFICIENTE:
   • INSE_MEDIO_norm = 18.45:
     "Para cada 1 desvio-padrão de aumento no INSE, 
      MEDIA_MT aumenta 18.45 pontos"
   
   • TIPO_ESCOLA_Privada = 28.67:
     "Escolas PRIVADAS têm MEDIA_MT 28.67 pontos MAIOR 
      que escolas PÚBLICAS (tudo mais constante)"
   
   • AREA_Rural = -12.34:
     "Escolas RURAIS têm MEDIA_MT 12.34 pontos MENOR 
      que escolas URBANAS"

2. ABRIR: outputs_tabelas/resumo_modelos_*.csv

   COLUNA: R2_ajustado
   • 0.6234 = modelo explica 62.3% da variação em MT
   • Quanto MAIS próximo de 1, melhor o ajuste
   • Menor que 0.3 = modelo fraco

   COLUNA: RMSE
   • 15.42 = em média, predições erram por ±15.42 pontos
   • Quanto MENOR, melhor

3. VISUALIZAR: outputs_figuras/diagnosticos_residuos_MT_*.png

   Painel 1 (canto superior esquerdo):
   • Título: "Resíduos vs Fitted Values"
   • Ideal: pontos aleatórios em torno da linha vermelha
   • Problema: se houver padrão (U, funil), há não-linearidade

   Painel 2 (canto superior direito):
   • Título: "Q-Q Plot"
   • Ideal: pontos sobre a linha vermelha diagonal
   • Problema: desvios nas caudas = não-normalidade

   Painel 3 (canto inferior esquerdo):
   • Título: "Scale-Location Plot"
   • Ideal: linha reta e horizontal
   • Problema: linha inclinada = heterocedasticidade

   Painel 4 (canto inferior direito):
   • Título: "Distribuição dos Resíduos"
   • Ideal: forma de sino (distribuição normal)
   • Problema: assimétrica ou com caudas pesadas

4. ABRIR: outputs_diagnosticos/resumo_testes_*.csv

   Coluna: Normalidade_p
   • > 0.05 = resíduos são normais (bom!) ✓
   • < 0.05 = resíduos não são normais ✗

   Coluna: Homocedasticidade_p
   • > 0.05 = variância é constante (bom!) ✓
   • < 0.05 = variância não é constante ✗

   Coluna: VIF_max
   • < 5   = multicolinearidade baixa (bom!) ✓
   • 5-10  = multicolinearidade moderada (investigar)
   • > 10  = multicolinearidade severa (problema!) ✗

   Coluna: DW (Durbin-Watson)
   • 1.5-2.5 = independência dos resíduos (bom!) ✓
   • < 1.5  = autocorrelação positiva ✗
   • > 2.5  = autocorrelação negativa ✗

================================================================================
CHECKLIST DE QUALIDADE DO MODELO
================================================================================

□ R² ajustado > 0.5?
  Se NÃO: modelo explica pouca variação. Considere:
    • Adicionar mais preditores
    • Verificar se há não-linearidades
    • Transformar variáveis dependentes

□ Todos os p-valores < 0.05?
  Se NÃO: há coeficientes não significativos. Considere:
    • Remover variáveis não significativas
    • Aumentar tamanho da amostra

□ Normalidade_p > 0.05?
  Se NÃO: resíduos não são normais. Impacto:
    • Testes de significância podem ser inválidos
    • Mas estimativas de coeficientes ainda são válidas
    • Solução: usar bootstrap ou transformação

□ Homocedasticidade_p > 0.05?
  Se NÃO: há heterocedasticidade. Impacto:
    • Erros padrão dos coeficientes são inválidos
    • Intervalos de confiança estão errados
    • Solução: usar erros padrão robustos

□ VIF_max < 10?
  Se NÃO: há multicolinearidade severa. Impacto:
    • Coeficientes são instáveis
    • Difícil interpretar efeito individual
    • Solução: remover variáveis correlacionadas

□ DW entre 1.5 e 2.5?
  Se NÃO: há autocorrelação. Impacto:
    • Comum em dados com estrutura temporal
    • Erros padrão subestimados
    • Solução: incluir lags ou usar modelos de série temporal

PERGUNTAS FREQUENTES
================================================================================

Q: "Qual é a diferença entre coeficiente e p-valor?"
A: 
  • Coeficiente = magnitude do efeito (quanto muda Y quando X muda 1 unidade)
  • P-valor = probabilidade de obter este resultado por acaso
  
  Exemplo: Coef = 28.67, p = 0.0001
  "Escolas privadas têm 28.67 pontos a mais em MT, com p = 0.01% de chance
   de este resultado ser apenas acaso. MUITO significativo!"

Q: "Devo remover variáveis com p > 0.05?"
A:
  Depende:
  • Se p > 0.05 e coeficiente é muito pequeno → remova
  • Se p > 0.05 mas faz sentido teórico → mantenha (pode estar mascarado)
  • Compare modelos com/sem a variável usando AIC ou BIC

Q: "Por que criar variáveis dummy?"
A:
  Regressão linear só funciona com números. Para variáveis categóricas
  (ex: "Público" vs "Privado"), criamos dummies:
  • TIPO_ESCOLA_Privada = 1 se privada, 0 se pública
  Isso permite incluir categorias no modelo.

Q: "Como interpretar um coeficiente de dummy?"
A:
  TIPO_ESCOLA_Privada = 28.67
  "Comparado à categoria de referência (Pública), Privadas têm 
   28.67 pontos ADICIONAIS em MEDIA_MT"

Q: "O que significa 'normalizado' (variáveis_norm)?"
A:
  z-score: (X - média) / desvio_padrão
  Transforma em escala padronizada:
  • Valores próximos de 0 = próximo à média
  • Valores > 1 = acima da média
  • Facilita comparação entre variáveis em escalas diferentes

Q: "Posso usar este modelo para fazer previsões?"
A:
  Sim! Os modelos RDS podem ser usados:
  
  modelo_mt <- readRDS("modelo_MT_*.rds")
  nova_escola <- data.frame(
    INSE_MEDIO_norm = 0.5,
    TIPO_ESCOLA_Privada = 1,
    AREA_Rural = 0,
    LOCALIZACAO_Interior = 1
  )
  predict(modelo_mt, nova_escola)

  → Ou: usar setwd() manualmente antes de source()

AVISO: "Alguns coeficientes têm p > 0.05"
  → Normal! Nem toda variável é significativa
  → Considere remover se não fazer sentido teórico
  → Refaça análise sem a variável e compare AIC/BIC

AVISO: "VIF > 10 em várias variáveis"
  → Multicolinearidade! Variáveis são correlacionadas
  → Tentar remover uma de cada par correlacionado
  → Ou: usar PCA ou regularização (Ridge/Lasso)

AVISO: "Normalidade_p < 0.05"
  → Resíduos não são normais (comum com grandes n)
  → Não invalida totalmente o modelo
  → Pode usar bootstrap para robustez
