═════════════════════════════════════════════════════════════════════════════

❓ "Aonde fico sabendo os arquivos foram criados?"
→ Procure em: TESTE/dados_por_escola/ e TESTE/processados/
→ Cada arquivo tem TIMESTAMP (20260511_143025)

❓ "Como mudo as escolas da comparação dois_escolas?"
→ Edite no topo do script:
   ID_ESCOLA_A <- 61432986  ← mude para outra
   ID_ESCOLA_B <- 61466120  ← mude para outra

❓ "Qual script executar PRIMEIRO?"
→ 1. ajeitar_dados.r
→ 2. classificar_escolas.r (⭐ necessário para os outros)
→ 3. Depois: comparar_grupos.r ou dendrograma.r

❓ "Demora muito?"
→ Normal! TS_ALUNO_34EM.csv tem 173k registros.
→ Primeira execução leva 1-2 min só para ler os dados.

❓ "Apareceu aviso sobre ggplot2?"
→ Normal. Não bloqueia a execução. 
→ Se quiser sumir: reinstale com install.packages("ggplot2")

❓ "Preciso rodar tudo de novo se tiver novos dados?"
→ Sim: ajeitar_dados.r → correlacao.r (modo="pendentes" roda só novas)
→ Depois: classificar_escolas.r → comparar_grupos.r → dendrograma.r
